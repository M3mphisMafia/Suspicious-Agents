# Security policy

Undertow Security is a defensive tool. If you find a vulnerability in this project, report it
privately, not in a public issue.

- Use GitHub's private vulnerability reporting: the repository's **Security** tab, then
  **Report a vulnerability**. Include the affected version or commit, what you found, and steps to
  reproduce.
- Allow reasonable time to investigate and release a fix before any public disclosure.

**Supported versions.** Fixes land on the latest release.

**Scope note.** This repository builds honeypot and deception components on purpose. Fake
credentials, canary keys and decoy data in the code and templates are inert by design and are not
real secrets. Don't report those as findings.
